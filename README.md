# Object-Level Change Detection in Aerial Drone Videos Using Deep Learning

## Project Overview
This project focuses on understanding object-level changes in aerial drone videos using deep learning and computer vision techniques.

The objective is to explore how objects can be detected and how changes in their appearance or presence can be analysed across video frames.

## Objectives
- Understand object detection in aerial drone videos.
- Explore deep learning approaches for object detection.
- Study changes in objects across video frames.
- Understand computer vision techniques for aerial video analysis.
